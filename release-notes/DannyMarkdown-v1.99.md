# Danny Markdown 编辑器 1.99

- 新增成熟的多标签页功能：支持在同一窗口打开多个文档、新建与关闭标签、拖拽调整顺序，以及像 Chrome 一样将标签拖出成为独立窗口或重新拖回。
- 全面升级 Markdown 编辑能力：新增飞书风格的悬浮工具栏，支持标题、列表、任务、加粗、删除线、斜体、下划线、超链接、代码和文字颜色等格式。
- 新增空白行快捷插入菜单，可快速添加标题、列表、任务、代码块、引用、高亮块、分割线、链接和图片。
- 完善代码块功能：支持语言选择、自动换行和一键复制；现在点击两个相邻代码块之间也能插入正文和换行。
- 新增飞书风格高亮块，支持颜色设置、文本选择、块内全选、复制和整块删除。
- 更新 App Logo，并新增支持覆盖安装的一体式拖拽安装器；安装后可重新登记 `.md` 和 `.markdown` 默认打开应用。
- 支持 Intel 与 Apple Silicon Mac，更新包继续使用 Sparkle EdDSA 签名验证。
